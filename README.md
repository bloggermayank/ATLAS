# ATLAS — The Imagined City

An immersive, interactive Mediterranean city experience.

## Stack
- React + Vite
- Three.js for the procedural 3D city
- Lucide icons
- Responsive editorial interface

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## City plan
Eight connected districts orbit the Grand Piazza: Old Quarter, Grand Piazza, Villa Terraces, Garden Quarter, Atelier District, Market Arcade, Sunset Heights, and Observatory Hill.

The current city uses procedural geometry as a performant foundation. Meshy hero assets can replace the fountain and observatory placeholders once model export is available.
